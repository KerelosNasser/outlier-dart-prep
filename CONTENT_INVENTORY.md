## 2. TASK TYPES (OUTLIER TRAINING SUITE)

- **Type A: Knowledge Assessment**: Theory, semantics, and tricky edge-case multiple-choice questions with full explanations.
- **Type B: Code Tracing**: Predict output, execution order, type promotion, or compile errors without running code first.
- **Type C: Coding Challenges**: Hands-on implementation tasks evaluated against automated unit tests.
- **Type D: Debugging Exercises**: Intentionally broken code requiring error diagnosis, fix implementation, and written justification.
- **Type E: Code Review**: Production-level code review evaluating correctness, null safety, complexity, and Effective Dart conventions.
- **Type F: Compare AI Answers**: Side-by-side comparison of Model A vs Model B Dart implementations with bug detection and comparative justification.
- **Type G: Prompt & Rubric Creation**: Simulation of RLHF authoring tasks (creating rigorous programming prompts, test specs, and multi-criteria rubrics).
- **Type H: Project Simulation**: Multi-step engineering projects (e.g., Typed JSON parser, Async task scheduler, Generic repository).
